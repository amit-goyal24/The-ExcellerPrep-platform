# ExcellerPrep — Capgemini 2027 Preparation Platform

A focused, responsive web application designed for campus placement assessment and recruitment preparation for Capgemini Exceller 2027.

---

## 📌 Features

- **Dashboard:** Modern welcome hero banner, visual circular Readiness Score (78/100), and key information stat cards.
- **Communication Assessment:** Interactive Business English & Grammar practice featuring 5 placement-aligned MCQs, real-time score calculation, and grammatical rule explanations.
- **About Project:** Project objectives, architectural overview, tech stack documentation, and 5-member collaborative work distribution.
- **Interactive Slides Deck:** Built-in presentation slides accessible at `/slides.html` with keyboard navigation and fullscreen support.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 16.4.3 (App Router)
- **Library:** React 19
- **Language:** TypeScript
- **Styling:** Tailwind CSS 4 & Custom CSS variables
- **Icons:** Lucide React

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. View Presentation Slides
Open [http://localhost:3000/slides.html](http://localhost:3000/slides.html).
